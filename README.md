# Мебельное производство

Веб-приложение на ASP.NET Core MVC, .NET 10, Entity Framework Core и PostgreSQL. Администратор ведёт клиентов, сотрудников, заказы и платежи. Исполнители работают со своими назначениями на замер, производство, доставку и сборку.

## Локальный запуск

1. Запустите PostgreSQL и создайте базу для приложения.
2. В Rider откройте `src/Furniture.Web/Furniture.Web.csproj`. Укажите свою строку подключения в `src/Furniture.Web/appsettings.Development.json` по примеру `appsettings.Example.json` или в переменной среды `ConnectionStrings__FurnitureDb`.
3. Запустите профиль `http` в Rider. Из терминала можно выполнить `dotnet run --project src/Furniture.Web --launch-profile http`.
4. Откройте [http://localhost:5282](http://localhost:5282). При запуске в Development приложение применяет миграции, добавляет демонстрационные учётные записи и заполняет пароли у старых демонстрационных учётных записей, где пароль ещё не был задан.

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `AdminDemo2026` |
| Замерщик | `measurer1` | `WorkerDemo2026` |
| Работник производства | `production1` | `WorkerDemo2026` |
| Доставщик | `courier1` | `WorkerDemo2026` |
| Сборщик | `assembler1` | `WorkerDemo2026` |

Для показа начните с создания заказа под администратором. Затем примите назначение под замерщиком, добавьте изделие и сохраните результаты замера. Администратор согласовывает состав и стоимость. Производство добавляет элементы и отмечает изготовление, после чего доставка и сборка отмечают свои количества. Заказ с остатком переходит в ожидание оплаты и закрывается после полного расчёта.

Для среды Production примените миграции к выбранной базе через EF Core и задайте `InitialAdministratorPassword` при первом запуске, чтобы создать начальную учётную запись `admin`. Для базы с настроенной учётной записью переменная больше не нужна.
